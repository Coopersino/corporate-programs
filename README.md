# Сравнение программ корпоратива

Статическая страница для публикации на GitHub Pages. Девять программ Pandora: цены пятницы, продолжительность в минутах, доплата до 35 000 ₽ и субъективный уровень кринжа.

На широком экране — таблица, на телефоне — карточки с теми же данными. Есть сортировка по цене и кринжу. Внешние зависимости и сборка не требуются.

Локальный просмотр: `python3 -m http.server 8765 --bind 127.0.0.1`

GitHub Pages: Deploy from a branch → main → / (root).

Суммы сохранены в согласованном виде. Сайт не бронирует мероприятия и не отправляет данные посетителей.
